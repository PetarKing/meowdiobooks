# Reporting a vulnerability

Meowdiobooks is alpha software. Identify the affected commit or release when reporting a security
issue. Update integrations to a newly verified release when a fix is published.

Report suspected vulnerabilities privately. If GitHub private vulnerability reporting is enabled,
use the repository's **Security → Report a vulnerability** control. Otherwise, contact the
[maintainer](https://github.com/PetarKing) to arrange a private reporting channel before sharing
technical details. Do not put credentials, private books, voice samples or exploit details in
public issues or pull requests.

Include the affected commit or release, operating system, reproduction steps, expected and actual
behavior, and a minimal synthetic or redistributable example. Redact tokens, local account paths,
and user data from logs and screenshots. No response-time guarantee is offered during the alpha.

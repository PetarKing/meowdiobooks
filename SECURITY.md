# Reporting a vulnerability

Security fixes target the latest supported V1 release. Identify the affected commit or release when reporting a security
issue. Update integrations to a newly verified release when a fix is published.

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/PetarKing/meowdiobooks/security/advisories/new).
Do not put credentials, private books, voice samples or exploit details in public issues or pull requests.

Include the affected commit or release, operating system, reproduction steps, expected and actual
behavior, and a minimal synthetic or redistributable example. Redact tokens, local account paths,
and user data from logs and screenshots. Reports are triaged by the maintainer; no guaranteed response time is offered.

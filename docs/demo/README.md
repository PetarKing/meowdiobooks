# The Last Door

The README features a 36.47-second performance of this original Meowdiobooks scene, with a narrator,
Elias, Marcus Vey and a shared line. [Download the MP3](the-last-door.mp3).

## Passage

Rain worried the observatory windows. Elias held the brass key to the emergency lamp.

**Elias:** “Marcus, tell me this is the key to the west stair.”

**Marcus Vey:** “It was, before someone folded the building.”

On its bow, an inscription read: Do not open after midnight.

“That is an oddly specific thing not to mention,” Elias said to Marcus.

**Marcus Vey:** “You saw it.”

And now it has seen you.

**Elias:** “Who said that?”

**Marcus Vey:** “Not me. The room has been borrowing voices all evening.”

**Elias + Marcus:** “Together, then.”

The key turned. Somewhere below them, an audience applauded.

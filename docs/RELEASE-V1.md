# Meowdiobooks V1.0

The first public baseline of the personal Meowdiobooks studio: import a PDF, EPUB or text file,
review source-linked dialogue and cast decisions, design or clone voices locally, and export
chaptered audio as M4B or MP3.

V1 includes the current heart identity, forest light/dark appearances, clearer mobile review,
resumable chapter generation and reusable approved voices. The application and shared workflow
packages are versioned together at 1.0.0. No persisted-data migration is introduced by the V1
version and documentation update.

## Getting started

Use the [source installation guide](SETUP.md) on an Apple Silicon Mac. Model downloads and media
tools are separate prerequisites. Review currently requires your own OpenAI API key; local audio
production is not a claim that the complete workflow operates offline.

The release includes `meowdiobooks_workflow-1.0.0-py3-none-any.whl`,
`meowdiobooks-workflow-ui-1.0.0.tgz` and `SHA256SUMS` for integrations. These assets are not an app
installer. GitHub's source archives provide the personal application's source checkout.

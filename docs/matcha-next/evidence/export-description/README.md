# Export description review

The local Studio fixture shows the [complete desktop edition preview](edition-preview-1440-dark.png), with the PDF page filling its column edge to edge and its source, page controls, and image action inside the faded lower page area. The [phone preview](export-390-light-top.png) and [phone create bar](export-390-dark-bottom.png) were checked at 390px; the browser run also covered 320px, both appearances, and regular/20-chapter books. [Browser results](report.json) verify natural full-page image height, zero top/side inset, controls inside the page, no horizontal overflow, page errors, or scoped axe violations. The script verified the default description, a custom edit, an intentionally blank description, and Reset.

The frontend sends the description through the same export request as title and author. Backend tests confirm JSON and multipart requests, a 2,000-character limit, persistence in the Library record, and legacy records without a description. Real FFmpeg/FFprobe package tests read the description tag back from M4B and both MP3 chapters in the ZIP. This evidence uses synthetic UI data and local media generation; no provider synthesis or production book was used.

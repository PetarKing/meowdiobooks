# Decisions with workflow consequences

| Problem and credible options | Decision | Evidence and trade-off |
| --- | --- | --- |
| Voice audition comparison required a separate “Approve Audition N” action after choosing. Leaving the second action preserves the old flow; applying on selection shortens it. | Clicking an audition card selects its exact revision immediately in the draft. Audio playback stays independent. “The Ghost” switches to the existing voice-creation controls; generating still requires its explicit action. Cast-stage acceptance remains separate and authoritative. | Cast interaction fixtures and focused tests verify revision selection, Ghost/Back and stage acceptance. An accidental card choice is reversible by choosing another audition before accepting Cast. |
| Accepted Review “Change settings” returned to a sparse manual Scan CTA. Always showing the CTA is explicit; automatically scanning removes a redundant step. | That intentional return launches the existing nonpublishing Review candidate scan once and shows in-page progress. Initial entry still exposes an explicit Scan action. Failure leaves Retry; no accepted review is replaced until ordinary acceptance. | App return/failure tests and the existing `process_review(... publish=False)` backend boundary. This spends local processing upon a clear editing action; no new provider route or publication authority is added. |
| Cast’s three native confirmations bypassed the product dialog and had inconsistent focus. | Use `DialogSurface` with explicit cancel/continue actions and focus restoration. The replacement still requires confirmation before editing the accepted Cast; a saved newer draft opens directly. | Browser keyboard/Escape and cancellation checks. The modal adds one intentional decision before changing accepted Cast, while removing the later redundant rebuild CTA. |
| The fixed-color decoration could contaminate custom host palettes or distract from content. | Mark custom semantic `PresentationRoot` palettes and show the new canopy only in the canonical studio. It sits behind content and moves by a few pixels; reduced-motion stops it. | Eight rendered mode/width/motion checks verify decoded art, no overflow and palette isolation. The image adds about 300 KB to the canonical style package. |

# Geist font assets

Unmodified WOFF2 files from the [geist 1.9.0 npm release](https://www.npmjs.com/package/geist/v/1.9.0),
retrieved 2026-10-30. Source: [Vercel Geist](https://github.com/vercel/geist-font).
The bundled [SIL Open Font License 1.1](OFL.txt) applies to these fonts independently of the application license.

The package archive is https://registry.npmjs.org/geist/-/geist-1.9.0.tgz.
No font outlines or names have been modified. Assets are served locally and included in the
workflow package through its existing `src` inclusion. No CDN, external font requests,
Next.js dependency, or system font installation is required.

Serif ships only Regular upright in this release. Heart changes dots and punctuation;
it is not an italic or a heavier weight. Sans supplies the variable 100–900 upright and italic faces.
